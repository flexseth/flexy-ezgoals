## [0.1.0] - 2026-07-19

### Added
- Initial release of EZ Goals plugin
- Custom goal block with WordPress block editor integration
- Four goal types: Near Term, Long Term, Stretch Goal, Daily Goal
- DateTimePicker component for deadline selection
- Color-coded urgency indicators (grey, blue, yellow, orange)
- Front-end goal display above post content
- Settings page for color customization
- REST API endpoints for goal CRUD operations
- Performance-optimized caching with WordPress transients
- Daily cron job for cache rebuilds
- Post meta storage for goal data
- i18n support with text domain `flexy-ezgoals`
- GPL-2.0-or-later license
